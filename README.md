# Tienda de Videojuegos

Proyecto web educativo de una tienda de videojuegos y accesorios relacionados. Su objetivo es practicar la creación de páginas web usando HTML y CSS, con apoyo de Bootstrap para organizar el diseño y lograr una visualización adaptable a distintos dispositivos.

## Objetivo

Construir una página web sencilla donde los usuarios puedan conocer los productos de una tienda de videojuegos, como juegos, controles, audífonos, consolas y otros accesorios.

## Tecnologías

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** colores, tipografías, tamaños y estilos visuales.
- **Bootstrap:** apoyo para el diseño responsive y componentes como menú, tarjetas y botones.

El proyecto está pensado para un nivel principiante, por lo que se busca utilizar código claro, ordenado y fácil de comprender.

## Estado actual

Por ahora existe una página inicial en el archivo `Inicio.html`. Esta contiene la estructura HTML básica y será el punto de partida para desarrollar el sitio.

## Funcionalidades planificadas

- Mostrar el nombre y la identidad visual de la tienda.
- Crear un menú de navegación.
- Presentar videojuegos y accesorios mediante imágenes, nombres y precios.
- Organizar los productos por categorías.
- Agregar botones de acción, por ejemplo, para ver detalles o agregar productos al carro.
- Adaptar la página para computadores, tablets y teléfonos.

## Cómo visualizar el sitio

1. Abrir la carpeta del proyecto.
2. Hacer doble clic en `Inicio.html`.
3. El archivo se abrirá en el navegador web predeterminado.

No se necesita instalar programas ni dependencias para visualizar la versión actual.
